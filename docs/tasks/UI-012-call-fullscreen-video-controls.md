# Task: полноэкранный видеозвонок и иконки управления

- **ID:** `UI-012`
- **Status:** `approved for implementation — manual APK testing`
- **Priority:** high
- **Source:** ручное тестирование APK Арсланом
- **Depends on:** текущий экран звонка UI Preview; системные нижние insets из `UI-011`

## Контекст и границы

Это задача **UI Preview**, без подключения настоящей камеры, микрофона,
WebRTC/LiveKit, сети или разрешений. Цель — сделать правдоподобный,
интерактивный макет видеозвонка в стиле WhatsApp, который будет затем
проверен в APK. Реальная камера/видео — отдельная будущая задача.

## Часть A — полноэкранная раскладка видеозвонка

### Убрать из центра экрана звонка

Не показывать в центральной части видеозвонка следующие элементы текущего
демо-макета:

- строку «видео 240p, ~4 МБ/мин»;
- блок этапов соединения («соединяем напрямую», «проверяем домашний узел» и
  подобные технические статусы);
- текст «Макет видео без доступа к камере»;
- большой круглый аватар с инициалами собеседника в **видеозвонке**.

Эта информация перегружает звонок и не должна закрывать визуальную область.
Оценка расхода может оставаться на отдельном экране/подтверждении *до* начала
видеозвонка, если такой сценарий уже есть, но не во время вызова.

### Раскладка

Сделать полноэкранный call UI по образцу WhatsApp:

1. **Исходящий видеовызов / пока идёт вызов:** весь экран занимает preview
   собственной камеры (для Preview — визуальный mock camera feed, не просьба
   к разрешению камеры). Сверху поверх видео: имя собеседника и краткий
   понятный статус «Вызов…».
2. **После условного соединения в UI Preview:** видео собеседника занимает
   весь экран. Свой preview — небольшая picture-in-picture (PiP) карточка в
   одном из верхних углов, с безопасными отступами от status bar.
3. PiP своего видео можно перетаскивать пальцем; она не выходит за видимые
   границы safe area, не закрывает критичные элементы и имеет достаточно
   большую touch-зону. Реальная медиалогика не нужна: перемещается mock-PiP.
4. Сверху поверх full-screen video остаются имя собеседника и таймер звонка
   после соединения. До соединения вместо таймера — «Вызов…».
5. Тап по свободной области экрана переключает видимость панели управления и
   верхнего оверлея. Скрытие/показ не должно завершать звонок, запускать
   навигацию или конфликтовать с drag PiP.
6. При скрытых контролах видео визуально почти полностью занимает экран.

Использовать текущие демо-данные/визуальные заглушки для mock video. Не
выдавать mock за настоящую камеру и не запрашивать runtime permission.

## Часть B — круглая панель управления с Lucide

### Требование

Текстовые кнопки («Микрофон выкл.», «Камера», «Тихо», «Завершить») заменить
на нижнюю горизонтальную панель равномерно расположенных **круглых
icon-only** кнопок. Использовать **только `lucide-react-native`**: никаких
emoji, текстовых суррогатов или самодельных SVG.

### Иконки и состояния

| Действие | Обычное | Выключенное/альтернативное | Правило |
|---|---|---|---|
| Микрофон | `Mic` | `MicOff` | Tap включает/выключает. В выключенном состоянии — белый круг, тёмная перечёркнутая иконка. |
| Камера | `Video` | `VideoOff` | Только видео-звонок. Tap включает/выключает mock video. Выключенное состояние как у микрофона. |
| Вывод звука | `Volume2` | `Ear` | `Volume2` — громкая связь, `Ear` — разговорный динамик. Tap переключает. Не называть кнопку «Тихо». |
| Смена камеры | `SwitchCamera` | — | Только в видеозвонке. Меняет mock front/back camera state; не открывает реальную камеру. |
| Завершение | `PhoneOff` | — | Красный круг; возвращает пользователя на логически предыдущий экран согласно `UI-010`. |

### Визуальные и layout-требования

- Кнопка: около **56 dp** (не меньше 48×48 dp touch target).
- Обычное состояние: тёмный полупрозрачный круг с белой Lucide-иконкой.
- Выключенные микрофон/камера: белый круг с тёмной перечёркнутой Lucide-иконкой.
- Завершение: красный круг с белой `PhoneOff`.
- Иконки визуально читаемые; ориентир 24–28 dp, без текста внутри кнопки.
- Ряд находится внизу, **над bottom safe-area / gesture inset** (`UI-011`), с
  равными промежутками и без обрезания на узких экранах.
- Доступность: добавить `accessibilityLabel`/role для всех icon-only кнопок;
  значение label отражает текущее действие («Выключить микрофон» /
  «Включить микрофон» и т.п.).
- При скрытии controls вся нижняя панель и верхний overlay исчезают. Тап по
  видео возвращает их. Не оставлять невидимые кнопки перехватывать касания.

- существующие компоненты/типы/демо-данные звонка в `src/ui/`;

Перед работой проверить, как Lucide подключён сейчас. Если библиотека уже есть,
использовать её существующий способ импорта, не создавать альтернативный набор
иконок.

## Acceptance criteria

- [ ] В видеозвонке удалены центральная строка расхода, технический список
  этапов, текстовая заглушка и большой аватар с инициалами.
- [ ] До соединения демонстрируется full-screen self mock-preview, имя и
  «Вызов…» поверх него.
- [ ] После условного соединения демонстрируется full-screen remote mock-video,
  имя + таймер сверху и небольшое draggable self PiP в безопасной зоне.
- [ ] Тап по свободной области корректно скрывает/показывает верхний overlay и
  нижнюю панель, без конфликта с перетаскиванием PiP.
- [ ] Панель использует только Lucide: `Mic`/`MicOff`, `Video`/`VideoOff`,
  `Volume2`/`Ear`, `SwitchCamera`, `PhoneOff`.
- [ ] Кнопки имеют визуальный размер около 56 dp, touch target минимум 48 dp,
  равные промежутки и корректный bottom safe-area inset.
- [ ] Микрофон, камера и вывод звука переключают заметное mock-состояние;
  завершение звонка возвращает на предыдущий экран, не закрывая APK (`UI-010`).
- [ ] Кнопки доступны через accessibility labels, даже без текстовых надписей.
- [ ] Нет запросов разрешений и попыток включить реальные камеру/микрофон.
- [ ] `npm run lint`, `npm test`, `npx tsc --noEmit` проходят.

## Manual APK test checklist (Hermes / Арслан)

1. Открыть видеозвонок и проверить, что полный экран визуально занят mock video,
   без старых центральных текстов и большого аватара.
2. Во время «Вызов…» проверить имя и статус сверху; после mock connection — имя
   и таймер, remote video full-screen, self PiP в углу.
3. Перетащить PiP: она движется плавно, остаётся на экране и не ломает controls.
4. Тапнуть по свободной части видео: верх и нижняя панель скрываются/появляются.
5. Нажать каждую кнопку и визуально проверить все состояния иконок.
6. Проверить, что SwitchCamera показывается только в видеозвонке.
7. Нажать PhoneOff: возвращает на предыдущий UI-экран, не закрывает приложение.
8. Проверить на жестовой навигации: ряд кнопок не попадает под gesture bar.
