# Task: системная кнопка «Назад» возвращает из чата к списку чатов

- **ID:** `UI-010`
- **Status:** `approved for implementation — manual APK testing`
- **Priority:** high
- **Source:** ручное тестирование APK Арсланом
- **Depends on:** текущая навигация UI Preview

## Баг

В Android APK при открытой переписке физическая/системная кнопка или жест
«Назад» сейчас закрывает приложение. Ожидаемое поведение — выйти только из
текущей переписки и вернуться на главный экран со **всеми чатами**.

## Целевой результат

Навигация обязана следовать истории экранов:

1. Пользователь открывает чат из общего списка.
2. Нажимает системную кнопку/жест Android «Назад».
3. Открывается главный экран со списком всех чатов, сохраняя ожидаемое
   состояние списка.
4. Только если пользователь уже находится на корневом экране списка чатов,
   Android может применить обычное системное действие выхода/сворачивания
   приложения.

То же поведение должно быть консистентно с видимой кнопкой «Назад» в шапке
переписки, если она есть: оба способа должны использовать один навигационный
переход и не расходиться по состоянию.

## Требования к реализации

- Обработать Android hardware back / back gesture в текущей архитектуре
  навигации UI Preview.
- Не допускать закрытия приложения, пока пользователь находится на дочернем
  экране: переписка, экран звонка, настройки или другой не-корневой экран.
- Для модальных состояний приоритет у ожидаемого закрытия модального UI;
  затем должен срабатывать возврат на предыдущий экран, а не выход из
  приложения.
- Не добавлять второй параллельный navigation stack и не ломать существующие
  тапы по чатам, нижнюю навигацию или экран звонка.
- Если текущая самодельная навигация уже имеет единый state/back-handler,
  расширить его минимально. Если используется навигационная библиотека,
  задействовать её штатный back handling.

## Acceptance criteria

- [ ] Открытый из списка чат: Android Back/Back gesture возвращает к списку
  всех чатов и **не** закрывает приложение.
- [ ] На корневом экране списка чатов системное поведение Android не
  перехватывается искусственно.
- [ ] На любом дочернем экране UI Preview (включая настройки и звонок, если
  применимо) Back возвращает на логически предыдущий экран, а не завершает
  приложение.
- [ ] Видимая кнопка «Назад» и системная кнопка/жест используют согласованное
  поведение.
- [ ] Нет двойного срабатывания Back, зацикливания экранов или сломанного
  скролла/нижней навигации.
- [ ] `npm run lint`, `npm test`, `npx tsc --noEmit` проходят.

## Manual APK test checklist (Hermes / Арслан)

1. Открыть любой чат из главного списка.
2. Сделать системный Android Back или системный back gesture.
3. Убедиться, что открылся список всех чатов, APK не закрылся.
4. Повторить из настроек и из экрана звонка, если эти экраны открыты.
5. На главном списке чатов нажать Back: убедиться, что применяется обычное
   системное действие Android, а приложение не уходит в навигационный цикл.
6. Сравнить с поведением экранной кнопки «Назад» в шапке чата.
