# APP-013L-01 — локальная уборка legacy-кода

## Контекст
Работа выполняется до ADR-002 и не добавляет сервер, сеть, endpoint'ы, ключи или SDK. Локальный SQLite остаётся единственным источником истины. UI-текст — русский; секреты и содержимое сообщений не логировать.

## Задача
1. Удалить `src/checks.ts` и связанный с ним мёртвый Canary-тест `__tests__/checks.test.ts`.
2. Проверить все production и test TypeScript/TSX импорты `src/networkInfo.ts`. Если импортов нет — удалить `src/networkInfo.ts`; если хотя бы один есть — не удалять и отразить это в отчёте.
3. Demo seed должен выполняться только в debug/development-сборке. В release-сборке seed данных не выполняется; приложение использует обычное локальное empty state. Добавить сфокусированный автоматический тест этого условия.

## Границы
- Не менять поведение других экранов и не проводить рефакторинг вне задачи.
- Не добавлять реальную сеть, URL, ключи, зависимости или серверный код.
- Не собирать APK, не коммитить и не пушить.

## Приёмка
- Удалённые legacy-файлы не имеют импортов/тестовых ссылок.
- В debug/development demo seed возможен; в release он гарантированно не запускается.
- Целевые тесты и полная команда ниже проходят.

## Проверка
```bash
(npm run lint && npm test && npm run typecheck && git diff --check) 2>&1 | tail -15
```
