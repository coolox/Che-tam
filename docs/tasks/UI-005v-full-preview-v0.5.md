## Что строим

Полностью автономный, offline UI-preview демо мессенджера "Hearth" (см.
`docs/spec.md` разделы 1, 7.1, 7.6, 7.10 для продуктового контекста —
**только для справки по смыслу экранов**, никакой реальной сети/сервера/
аутентификации не реализуется).

### Границы (обязательно)

- Нет: авторизация, сервер, сеть, WebSocket, Supabase, реальная камера/
  микрофон, реальные звонки, отправка медиа, сбор личных данных, аналитика,
  push-уведомления, доступ к контактам.
- Есть: интерактивная навигация, демо-семья (фиктивные имена/аватары из
  инициалов), демо-чат с локальной отправкой текста в памяти, экраны звонка
  (визуальные, без реального медиа), настройки/профиль/трафик, экран
  соединения — всё локальное, без персистентности (кроме опционального
  in-memory state).

### Экраны (объединяет UI-001…UI-006)

1. **Foundation / design system** (UI-001): design tokens (цвета, отступы,
   типографика, radius) в одном модуле. Светлая тема, русский язык,
   оригинальный глубокий зелёный акцент, тёплый нейтральный фон, читаемая
   типографика, тап-зоны 44+ dp. Верхний хедер "Hearth", нижние табы:
   `Чаты`, `Звонки`, `Семья`, `Настройки`.
2. **Welcome / demo entry** (UI-002): приветственный экран, кнопка
   "Посмотреть демо" ведёт в чаты, "Как это работает" разворачивает
   локальное объяснение. Состояние первого входа — только in-memory.
3. **Family chat list** (UI-003): 5-6 фиктивных семейных чатов, аватары из
   инициалов/цветов, превью последнего сообщения, время, бейдж непрочитанных,
   индикатор профиля трафика. Есть поиск (визуальный), empty state. Тап
   открывает чат (экран 4).
4. **Conversation UI** (UI-004): пузыри свои/чужие, разделители дат, галочки
   доставки, поле ввода, плейсхолдер вложения. Ввод текста и отправка
   добавляет исходящий пузырь в память (без сети/персистентности). Кнопка
   назад возвращает в список чатов. Layout безопасен с клавиатурой.
5. **Call UI prototypes** (UI-005): запускаются из чата — исходящий вызов,
   лестница статусов соединения, активный аудио-экран, активный видео-экран
   (макет, БЕЗ реального доступа к камере/микрофону). Локальные переключатели
   мик/камера/динамик визуально меняют состояние, кнопка завершения
   возвращает в чат. Понятный русский текст качества/трафика (например
   "соединяем напрямую", "видео 240p, ~4 МБ/мин").
6. **Profile / traffic / connection settings** (UI-006): фиктивный профиль,
   селектор профиля трафика (`Полный` / `Экономный` / `Минимальный`),
   карточка расхода за месяц, карточка статуса соединения, локальные
   переключатели. Никакого реального endpoint/аккаунта/диагностики/туннеля.

### Новое в v0.5 (relative to последнего известного APK v0.4.0)

Раз исходники v0.4.0 утеряны, ты пишешь всё заново, но ЦЕЛЬСЯ выше названия
последнего APK ("local-search-organization" подсказывает, что там был поиск
по чатам и какая-то организация/группировка). Дополнительно к экранам выше
добавь:

- Рабочий (локальный, по in-memory данным демо-чатов) поиск в списке чатов —
  fuzzy или substring match по имени/последнему сообщению, обновляется по
  вводу.
- Простая организация чатов: закреплённые чаты сверху списка (можно закрепить
  долгим нажатием, состояние в памяти).
