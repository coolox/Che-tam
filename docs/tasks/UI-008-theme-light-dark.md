# Task: светлая и тёмная тема для UI Preview

- **ID:** `UI-008`
- **Status:** `approved for implementation`
- **Depends on:** UI-001…UI-005v (текущий демо-мессенджер)

## Контекст

Сейчас в `src/ui/tokens.ts` — один плоский набор цветов (`colors`), захардкоженный
на светлую тему. Нужно два набора — светлый и тёмный — с переключателем.

## Задача

1. В `src/ui/tokens.ts` разделить `colors` на две темы: `lightColors` и
   `darkColors` с одинаковым набором ключей (`accent`, `background`, `surface`,
   `text`, `textMuted`, `border`, и т.д. — сохранить все существующие ключи).
   Подобрать тёмные аналоги (тёмный фон, светлый текст, тот же акцентный зелёный
   или его светлее вариант для контраста на тёмном фоне).
2. Добавить механизм выбора активной темы:
   - React Context (`ThemeProvider` / `useTheme()`) в `src/ui/theme.tsx` (новый
     файл), который отдаёт текущий набор `colors` + сам режим (`'light' | 'dark'`)
     + функцию переключения.
   - Стартовое значение — системная тема устройства через
     `useColorScheme()` из `react-native`, с возможностью пользователю
     переопределить вручную.
3. Добавить переключатель темы в экран настроек (там же, где `TRAFFIC_MODES` —
   смотри `src/ui/demoData.ts` и экран настроек в `App.tsx` / `src/ui/state.ts`
   для существующего паттерна выбора режима). Три варианта: "Системная",
   "Светлая", "Тёмная" — как сегментированный контрол, в том же стиле, что
   существующий выбор трафик-профиля.
4. Прогнать по всем экранам: список чатов, чат, звонок, настройки — заменить
   везде прямые ссылки на статичный `colors` (импорт из `tokens.ts`) на
   `useTheme().colors`, чтобы все экраны реагировали на смену темы.
5. Сохранять выбор пользователя между запусками через `AsyncStorage` (тот же
   пакет, что уже используется в `src/storage.ts` для канарейки — не путать
   файлы, это про UI Preview, отдельный ключ в сторадже, например
   `ui_theme_preference`).
