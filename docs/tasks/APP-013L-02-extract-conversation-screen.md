# APP-013L-02 — вынести экран переписки из PreviewAppShell

## Контекст
Работа выполняется до ADR-002: никакого production-сервера, сети, endpoint'ов, ключей или SDK. Локальный SQLite — источник данных UI. UI-текст остаётся русским. `PreviewAppShell.tsx` — legacy UI monolith, который следует постепенно разделять.

## Задача
Вынести экран открытой переписки из `src/app/PreviewAppShell.tsx` в отдельный компонент в `src/app/screens/` без изменения поведения, визуальной структуры, доступности, обработчиков и используемого локального состояния. `PreviewAppShell` должен только передавать нужные props/handlers в извлечённый экран.

## Границы
- Вынести только экран переписки; остальные экраны не переносить.
- Не менять тексты, навигацию, demo/SQLite flow, состояние звонков или стили намеренно.
- Не добавлять зависимости, сеть, URL, ключи, серверный код.
- Не собирать APK, не коммитить и не пушить.

## Приёмка
- Conversation screen находится в `src/app/screens/` и рендерится через `PreviewAppShell`.
- Поведение остаётся прежним; существующие тесты адаптированы/добавлены только по необходимости.
- Линтер, все тесты, typecheck и diff check проходят.

## Проверка
```bash
(npm run lint && npm test && npm run typecheck && git diff --check) 2>&1 | tail -15
```
