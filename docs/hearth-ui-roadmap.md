# Hearth UI Preview — дорожная карта

## Цель первой поставки

Отдельный устанавливаемый Android APK `Hearth Preview`, который можно поставить рядом с Canary и оценить в Турции. Это интерактивный интерфейс с демо-данными: ни сервер, ни реальные аккаунты, ни звонки, ни отправка медиа не подключаются.

## Дизайн-решение

- Русский язык, светлая тема.
- Простой современный мессенджер, знакомый по логике WhatsApp: зелёный акцент, список чатов, пузыри, нижняя навигация.
- Hearth не копирует брендинг WhatsApp: собственные название, иконка, отступы и компоненты.
- Крупные зоны нажатия и контраст для родственников.

## Границы UI Preview

Есть: интерактивная навигация, демо-семья, чат, локальная демо-отправка текста, экраны звонка, настройки и экран соединения.

Нет: авторизация, сервер, сеть, WebSocket, реальная камера/микрофон, реальные звонки, медиа, сбор личных данных. Canary остаётся отдельным приложением и не меняется.

## Процесс

1. Выполняется ровно один task-файл.
2. Перед следующим task Hermes проверяет требования, код и тесты.
3. Контекст делегированному код-агенту — только файл task, нужные пути и команды; кратко, без повторов.
4. В середине UI Preview не добавляются backend, учётные данные или сетевые вызовы.
5. APK отдаётся только после независимой сборки и верификации.
